HOW I WORK

The dashboard is the end of the process, not the beginning.

01

Trust the data?

Audit definitions, dates, duplicates, relationships and analytical populations before calculating the headline metric.

02

Define the question.

Separate a descriptive signal from an explanation, and make the denominator visible instead of burying it inside a measure.

03

Build the analysis.

Use SQL, Power Query, modelling and DAX where they add value — not because every project needs every tool.

04

Return to the decision.

Translate the finding into a next business question, a scenario or a data-quality action without overstating what the data proves.
